실행 설정

손 포인트: 아래 "찍는 대상"을 손으로 바꾼 뒤(또는 H 키) 카메라마다 손 위를 클릭하세요(파랑 네모 = 포함). 손이 둘이면 손마다 한 번씩 찍습니다. 다른 사람 손처럼 빼야 할 곳은 Shift+클릭 또는 오른쪽 클릭(주황)입니다. 이 방식은 손 텍스트 분할(기준선·손 ROI 확대)을 하지 않으므로, 첫 프레임에 손이 보이지 않는 카메라가 있으면 "물체 포인트 + 손 텍스트"를 쓰세요.

찍는 대상:

카메라마다 첫 프레임에서 물체 위를 클릭하세요(초록 = 포함). 물체가 아닌데 잡힐 것 같은 곳(책상·손 등)은 Shift+클릭 또는 오른쪽 클릭으로 제외(빨강)합니다. 물체 중앙 근처에 1~3개면 충분합니다. 위 분할 대상 텍스트로 같은 종류의 물체를 먼저 찾고, 클릭한 물체를 고릅니다.

카메라마다 첫 프레임에서 물체를 드래그로 감싸세요. 다시 드래그하면 바뀝니다. 물체 가장자리에 꼭 맞게 그립니다. 여백이 크면 물체 대신 주변 책상이 선택될 수 있습니다. 위 분할 대상 텍스트도 함께 사용합니다.

나에게 분배·배정된 RAW를 하나씩 보여 줍니다. 카메라 4장 모두 첫 프레임에서 물체 위를 클릭(초록 = 포함, 카메라당 최대 20개)하고, 물체가 아닌데 잡힐 것 같은 곳은 Shift+클릭 또는 오른쪽 클릭(빨강 = 제외)합니다. "완료 · 다음"을 누르면 대기열에 들어가고 바로 다음 RAW가 나옵니다. 대기열은 완료한 순서대로 한 개씩 RAW 전처리 → SAM3를 실행하고(동시 실행 한도와 무관), SAM3가 끝나면 마스크 검수로 넘어갑니다.

SAM 이후 · 3D 복원 일괄 실행

SAM3 → 마스크 검수 → 추적 → 추적 검수까지 끝난 실행은 3D 복원 대기가 됩니다. 여기서 3D 복원 일괄 실행(3D 복원 → MANO → 저장)을 바로 시작할 수 있습니다(작업 현황의 3D 복원 일괄 실행과 같은 기능).

불러오는 중…

이 PC · 3D 복원 일괄 실행 (3D 복원 → MANO → 저장)

첫 실행은 추적 검수까지만 하고 '3D 복원 대기'가 됩니다. 이 일괄 실행이 고른 순서대로 에피소드마다 3D 복원 준비 → 3D 복원 → MANO 피팅 → 결과 검사 → 최종 저장을 합니다. 이미 3D 복원까지 끝난 예전 'MANO 대기' 실행은 MANO부터 합니다. 첫 실행 뒤 파이프라인 코드가 바뀐 에피소드는 3D 복원 준비부터 다시 고정한 뒤 진행하고, 설정 파일이 바뀐 경우는 건너뜁니다. 체크하면 이미 3D까지 끝난 에피소드 중 업데이트 전 코드로 만든 것도 3D 복원부터 다시 합니다(이전 결과 보관).

대기·일괄 실행은 PC 동시 실행(최대 2개)에 포함되지 않습니다. 퇴근 후 한 번에 실행해 두세요. 평일(월~금) 오전 9시가 되면 그때 진행 중인 에피소드까지만 끝내고, 나머지는 다시 대기로 남습니다.
