승인된 추적 → 3D 복원 → 로컬 3D 확인

실행 (출력 경로 자동):
python3 00_scripts/10_reconstruct.py 05_tracking/approved/<episode>
완료하면 로컬 3D 창을 엽니다. --no-view를 추가하면 자동 열기를 생략합니다.
--check: 승인 입력·CUDA·라이브러리 확인만 수행 (모델 전체 추론 검증은 아님)
--new-attempt: 기존 3D 폴더를 99_history에 보관하고 새 실행
같은 명령 재실행: 해시로 검증된 완료 단계는 재사용합니다.
중단된 단계는 처음부터 다시 실행하며, 재생성한 단계 이후 산출물도 다시 계산합니다.

검증 및 로컬 표시 데이터 생성
HaMBA/MANO 손 메시 피팅과 최종 ZIP은 포함하지 않습니다.
기준 프레임이나 모델 정합 실패 시 자동으로 다른 프레임/설정으로 바꾸지 않고 중단합니다.

python3 00_scripts/11_review_3d.py 06_reconstruction/<episode>

3D 노이즈 후보 검수 (SOR + 군집):
11_review_3d.py의 노이즈 분석 버튼으로 전체 유효 추적점을 분석합니다.
SOR는 흩어진 고립점, 군집 검사는 작고 멀리 떨어진 덩어리를 후보로 잡습니다.
설정값은 작업용 초기값이며 KAIST 납품 합격 기준이 아닙니다.
손가락 끝/가려진 영역도 후보가 될 수 있으므로 원본·후보·제거 후 비교를 확인하세요.
적용은 검수자가 실행하며 원본 좌표와 추적 ID를 보존한 정제본을 별도 저장합니다.
noise/ 아래에 분석 설정, 후보 사유, 표시 데이터, 적용 기록과 정제본을 저장합니다.
이 적용은 추적점에 한정됩니다. 기존 메시와 final_data.pkl은 자동 재생성하지 않습니다.

물체·손 구분: 파란 원은 물체, 주황 사각형은 손입니다. 후보는 중심 색·모양을 유지하고 테두리로 SOR(자홍), 군집(노랑), 중복(빨강)을 표시합니다.
점 표시 대상에서 물체만/손만 볼 수 있습니다. 이는 화면 필터이며 적용 버튼은 물체·손 전체 후보에 적용합니다.

물체·손 독립 노이즈 검수 (최신):
- 기본 SOR: 물체와 손 각각 이웃 31, 표준편차 배수 8.0.
- 각 행에서 SOR 이웃/배수, 군집 반경/최소 점을 별도로 조절합니다.
- 물체 후보 계산 → 물체 제외 적용 / 손 후보 계산 → 손 제외 적용.
- 한쪽 계산/적용/해제는 다른 쪽에 영향을 주지 않습니다.
- 설정을 바꾼 뒤에는 해당 대상의 후보를 다시 계산해야 적용할 수 있습니다.
- noise/object/, noise/hand/ 아래 분석과 applied/ 정제본·검수자·시각을 별도 저장합니다.
- 기존 noise/ 루트의 통합 분석·정제본은 이전 기록으로 보존하며 새 화면에서 재사용하지 않습니다.
- 표시 체크박스는 화면만 제어합니다. 적용 범위는 누른 물체/손 버튼에 해당하는 전체 프레임입니다.
- SOR 후보: 물체 자홍색, 손 청록색. 이전 색상·통합 적용 안내보다 이 설명을 우선합니다.

표시 포인트 수:
상단에서 물체/손 정상점 최대 수를 각각 조절하거나 전체 유효점을 선택합니다.
노이즈 후보는 제한과 관계없이 모두 표시합니다. 제한값은 정상점에 대한 상한입니다.
현재 프레임별 원본 유효 수, 후보 제외 후 수, 실제 렌더에 전달하는 표시 수를 보여줍니다.
표시 수에는 화면 밖이나 다른 점에 가려진 점도 포함됩니다. 비교 모드에서는 전→후를 표시합니다.
review/point_cache는 원본 유효점의 표시용 캐시이며 원본/필터 적용본을 변경하지 않습니다.
전체 보기의 반응 속도는 유효점 수와 창 크기에 따라 달라집니다.
